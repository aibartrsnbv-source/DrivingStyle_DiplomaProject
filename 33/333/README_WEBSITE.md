# DriveGuard AI — Веб-интерфейс

## Запуск сайта

1. Установить зависимости:
   ```bash
   pip install -r requirements.txt
   ```

2. Обучить модели (если ещё не обучены):
   ```bash
   python main.py --synthetic
   ```

3. Запустить сервер:
   ```bash
   python server.py
   ```

4. Открыть браузер:
   ```
   http://localhost:8000
   ```

## Использование

- Выбери модель из списка
- Выбери источник: USB камера или видеофайл
- Нажми "Начать анализ"
- Система автоматически оповестит о рисках ДТП

## Структура

```
driving_style_ml/
├── server.py          ← FastAPI бэкенд (WebSocket + REST API)
├── web/
│   └── index.html     ← Весь фронтенд (HTML + CSS + JS в одном файле)
└── temp/              ← Временные загруженные видеофайлы
```

## API

| Метод | URL | Описание |
|-------|-----|----------|
| GET | `/` | Главная страница |
| GET | `/api/models` | Список доступных моделей |
| POST | `/api/upload-video` | Загрузка видеофайла |
| WS | `/ws/{session_id}` | WebSocket для реального времени |
